# R235 — 用 100 样本分布重算：未归属 3.457 s/step 是**稳定的真实量**，不是单样本噪声

## 一、目的

R234 的自查发现此前模块钩子只保留最后一次调用样本，故“3.43 s/step”只有单样本精度。
本轮把探针改为**逐调用追加样本**，输出 `calls / median / p10 / p90 / min / max`，重跑一个测量步。

**步时不变性**：17.9904 s vs 基准 17.928 s = **+0.062 s**（阈值内），8 rank 全部完成。
每次运行的采样数 = (warmup 1 + 测量 1) × 50 块 = **100 次/标签**。

## 四、结论

1. **未归属量在 100 样本下稳定**：`attn` 25.0、`mlp` 34.8、`block` 9.4 ms/block，
   合计 **3.457 s/step**，与 R231 的单样本估计 3.43 s 一致。⇒ 这不是采样方法造成的假象。
2. **六个外部机制全部否证**（权重等待 R228、allocator 争用 R229、审计同步 R230、
   guard 同步 R233、host 派发 R234A、分配阻塞 R234B）。
3. 因此这 3.46 s 只能是**父区间内我们尚未挂到钩子的设备执行**，或事件之间设备侧的间隙。
   已知 `mlp` 缺口里只有 `silu` 0.31 ms 被量到，而 `chunk`、两次 `.float()`、`multiply`
   都没有独立计时——它们合计独立测试仅 3.6 ms，仍差约 31 ms。
4. **下一步必须做父区间内的逐 op 计时**（不重写数学，只按原顺序调用并插入事件），
   才能定位这 31 ms 究竟是哪一个 op 或哪一段间隙。
