# R163 — 155 条检查的等价快速实现：**判定完全一致**，每次快 2.63×

## 做法

只用归约的实现 vs 原生实现，**逐调用比对**（原生判定仍是权威、检查一条不减、模型算术不动、不采纳任何东西）。

| | 原生 `ieee_nonfinite_masks` | 快速实现 |
|---|---|---|
| 非有限计数 | format cast + contiguous **整张量拷贝** → int16→int32 **扩张 2×** → 3 个全尺寸 mask → 求和 | `isnan(x).sum() + isinf(x).sum()` |
| 饱和计数 | `(x.abs()==65504).sum()`（又一个临时） | `max(x)==65504` 或 `min(x)==-65504` |

等价理由：FP16 最大有限幅值就是 65504，所以"存在 |x|==65504" ⟺ 极值达到 65504。

## 结果（8 rank 完成）

| 项 | 值 |
|---|---|
| 比较次数 | **465**（= 3 次前向 × 155） |
| **判定不一致** | **0**（`equivalent_on_every_call = True`） |
| 原生中位/次 | **24.253 ms** |
| 快速中位/次 | **9.234 ms**（**2.63×**） |
| 每步设备耗时 | 原生 **3.76 s** → 快速 **1.43 s** |

**非有限计数与饱和计数逐条完全一致。**

## 原生为什么贵

`ieee_nonfinite_masks`：`npu_format_cast` + `.contiguous()` **拷贝整张量**，`.view(int16).to(int32)` **扩张一倍位宽**，
再生成 **3 个全尺寸 mask** 才求和。最大张量是 `blocks.*.mlp.fc1` 的 **[10448, 14336]**。
