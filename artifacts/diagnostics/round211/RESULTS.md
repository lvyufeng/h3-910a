# R211 — **所有单算子都逐位可重复** ⇒ 非确定性在"组合/机制层"，不在算子里

## 一、这轮测了什么

R210 证明 HCCL all-reduce 逐位可重复，于是假设转向**算子层面**。
本轮实测：**单卡、单流、相同输入、重复 10 次、逐位比较**。

## 二、结果：**全部可重复**

| 算子 | 形状 | distinct | 可重复 |
|---|---|---|---|
| `matmul` QKV | 41792×5120 @ 5120×5120 | **1** | ✅ |
| `matmul` MLP fc1 | 41792×5120 @ 5120×25600 | **1** | ✅ |
| `matmul` MLP fc2 | 41792×25600 @ 25600×5120 | **1** | ✅ |
| `matmul` out_proj | 41792×5120 @ 5120×5120 | **1** | ✅ |
| `sum(dim=-1)` | 41792×5120 | **1** | ✅ |
| `max(dim=-1)` | 41792×5120 | **1** | ✅ |
| **RMSNorm (fp32)** | 41792×5120 | **1** | ✅ |
| residual add (fp16) | 41792×5120 | **1** | ✅ |
| softmax (fp32) | 128×304 | **1** | ✅ |

**VERDICT: all_reproducible —— 9 个算子、4 个模型真实 GEMM 形状，全部逐位稳定。**

（FA 内核本次没测成，见第四节。）

## 三、这个结果的推论很强

现在已有两组否证：

| 层 | 结论 | 来源 |
|---|---|---|
| **集合通信**（HCCL all-reduce，8 rank） | **逐位可重复** | R210 |
| **单算子**（matmul/norm/softmax/add，单卡） | **逐位可重复** | **R211** |

**而整个 DiT 50 块跑两次却有 relRMS 0.026% 的差异（R128）。**

**⇒ 非确定性只能来自"把算子组合起来的那一层"**，而不是数学本身。候选收窄为：

| 候选 | 为什么符合现有证据 |
|---|---|
| **权重 offload/prefetch 的异步拷贝与计算竞争** | 恰好是 #4 的领域；逐块 offload 每步都在搬权重 |
| 多 stream 交错 | 单算子测试是单流，真实路径是多流 |
| allocator 复用/地址依赖 | 不同地址可能选不同 tiling |
| 多卡 TP2+USP4 下的 collective 与计算交错 | HCCL 本身确定，但**交错顺序**可能不同 |

## 四、FA 内核没测成（诚实记录）

`flash_attention_910a` 报 `sequence length must be a positive multiple of 16`，
连 seq=4096（确实是 16 的倍数）也报。

读源码定位到 `fa910a.py:107`：

```python
def _kernel_sequence_length(n, d, enabled=True):
    if not isinstance(n, int) or n <= 0 or n % 16:
        raise FlashAttn910AError("sequence length must be a positive multiple of 16")
```

**说明传进去的 `n` 不是我给的 seq。** 最可能的解释：该接口期望 **(B, H, N, D)** 布局，
而我传的是 (B, N, H, D)，于是它把 **heads=7** 当成了序列长度（7 % 16 ≠ 0）。

**本轮上下文不足以再改一轮验证，留待下轮。**

## 五、这对 #4 意味着什么（重要）

若"算子确定 + 通信确定"，那么 #15 的 0.026% 差异**最可能就出在 #4 所管的 prefetch/拷贝生命周期上**。

**换句话说：#15 与 #4 可能不是"#15 阻塞 #4"，而是同一个问题的两面。**
这条链路一旦证实，#4 的实施依据就从"猜测"变成"已知这里有竞争"。

## 六、诚实边界

- **FA（占单步 41.5% 的最大项）本轮未测得**，所以"所有算子可重复"严格说是
  "除 FA 外全部可重复"。
- 单流单卡测不出多流/多卡交错导致的问题——**本轮的"可重复"不等于真实路径可重复**，
  这正是第三节推论的基础，也是它的局限。
- 10 次重复对极低频抖动可能不够。
