# AscendC FA 内核重写（用户 2026-11-25 决定立项，目标 ≤105 ms/块 ⇒ DiT 15 s/step）

## 立项依据

- **配置空间饱和**（R291）：`Br×Bc ≤ 65,536`（L0C 256 KB），64/912、64/960、64/1024 实测
  **126.12–126.19 ms**，差异 0.06% ⇒ 126.1 ms 是当前 TIK 内核体的结构性下限；
- 到 15 s 需要 FA **≤105 ms**（再快 17%）；DiT 单步还需非 FA 再省 ≥0.3 s；
- 现有 TIK 实现无法做双缓冲：`Sij`(76 KB)+双份+`Oij`(64)+`Oi`(64) = 280 KB > UB 192 KB（R278）；
  小 tile 又会慢 62%（R280）⇒ 只能在**显式管理 UB/L1/流水**的 AscendC 里做。

## 目标与验收

| 项 | 目标 |
|---|---|
| 内核时间 | **≤105 ms/块**（同形状 B1 H7 N41792 D128，同 seed 20261124） |
| 数值 | `max_abs_diff` / `relRMS` 相对参考（TIK 变体）不劣于 1e-04 量级；逐项报用户 |
| 语义 | dense、FP16 输入、FP32 softmax（max-subtract + exp + sum）、FP16 输出、无 1/sqrt(d)（调用方已 scale） |
| 约束 | 不改整网结构；不改 50 块/49 步/155 检查；不改默认部署，直到通过数值闸门与用户批准 |

## 里程碑

| 阶段 | 内容 | 通过判据 |
|---|---|---|
| **S0** | AscendC 工具链冒烟：`msopgen` 生成骨架 → `build.sh` → 在 910B 上跑通最小 kernel | 输出正确 + 可重复运行 |
| **S1** | FA 单块等价实现（无优化）：QK^T → max → exp → sum → PV，FP16/FP32 语义对齐 | 与 TIK 版 `relRMS ≤ 1e-04`，ms 记录 |
| **S2** | 流水化：cube/vector 双缓冲、MTE 预取 K/V；UB 显式分配（每块 ≤192 KB） | ms ≤ 126（追平）；再接 ≤105 |
| **S3** | 数值闸门（R283 工具）+ 8 rank 单步（叠加现交付组合） | relRMS 在原生带内、步时下降 |
| **S4** | 49 步全量 | 步时 ≤15 s 且数值达标 |

## 风险

- AscendC 对 910B 的 FA 类负载样例有限，S1 的等价实现与 S2 的流水可能需要多轮调试；
- 即使 S2 达到 105 ms，非 FA 仍需 ≥0.3 s ⇒ 15 s 仍可能差一点；届时应据实报告；
- 全流程不改默认部署，任何数值变化单独报批。
