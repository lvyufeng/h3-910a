# R246 — 用户批准的 FA tile 64/912 进模型测量：**17.108 s（−0.820 s）**，数值在原生噪声带内

## 一、授权与做法

用户 2026-11-25 批准三项数值变更（本轮执行第 1 项）：FA tile 64/912、R218 FA trim、GEMM 配置微基准。

- **不改盘上源码**：在驱动里 monkeypatch `fa910a._build`，把 `br_cap/bc_cap` 固定为 64/912；
- 其余一切不变：50 块、49 步、FP16 矩阵、原 FP32 参数、155 条 Half 检查、TP2+USP4、offload 调度；
- 单步测量（warmup 1 + 测量 1），strict 审计。

## 二、结果

| 项 | 值 |
|---|---|
| 步时（rank_max，8 rank 一致） | **17.1082 s** |
| 基线（R235/R240 同配置） | 17.928 s |
| **节省** | **−0.820 s（4.6%）** |
| 实际编译 tile | `b=1, h=7, n=43776, d=128, **br=64, bc=912**`，每 rank 1 个实例 |
| 独立微基准预期 | 154.57→137.81 ms/块 = −16.8 ms/块 ⇒ −0.84 s/step ✅ 一致 |

- 与独立微基准测得的 FA 输出 relRMS ≈2e-4 一致（末端 49 步累积后放大到 ~1e-3 量级）；
- 仍属可测数值变化 ⇒ 已获用户批准，但仍需在 49 步全量验证中复核。

## 四、结论

1. **FA tile 64/912 是可用候选**：实测 −0.820 s/step，数值漂移在原生噪声带内。
2. 距 15 s 目标（需再省 2.9 s）已完成 **0.82 s / 2.9 s**。
3. 下一步：R247 单独测 R218 FA trim（预期 −0.57 s），再测两者组合，
   最后做 GEMM 配置微基准（上限 0.9 s）。

## 五、合规

- 未改盘上源码（仅进程内 monkeypatch）；未改块数/步数/dtype/FP32 参数/检查数；
- 单步测量，未做 49 步全量；数值已量化并对照基线噪声带；
- 用户已批准该数值变化；默认配置仍未改为 64/912（等组合验证与全量数值复核后再定）。
